# 今日訓練 v8

純靜態網站，無安裝／編譯步驟。將 index.html、app.js、workout-plan.js、.nojekyll 放在 GitHub Pages 同一層，更新所有檔案。

## 使用

- 日期固定為台灣時間今天；完成的動作永遠記在實際今天。
- 週三至週六為基準重訓日，週一預設羽球，其餘預設休息。
- 「今天想練哪一套」可整套改練其他日子的課表；每張卡片可單獨改群組與器材。
- 每天最多三項，可自由排序。不記錄逐組進度與重量。
- 點「開始此項」鎖定項目；「停止／解除鎖定」可重新選擇。完成後可取消完成。
- 完成一項表示該動作全部正式組已完成。這是群組完成次數，不是精確的各肌群有效組數。
- 「更新推薦」只替換未開始、未完成的項目。切換整套課表需先停止已開始項目、取消完成。
- 切回休息／羽球不刪除已記錄的訓練；不想保留時請撤回完成。
- 一週課表分別显示原定安排、實際完成、目前推薦。按「今天改練這套」套用至今天，不是改寫該星期的完成紀錄。
- 最近 14 天紀錄可查看及撤回。刷新不清除紀錄。

## 推薦規則

每週一至週日計算目標。目標直接取 workout-plan.js 中 trainingDays（週三至週六）的群組次數；週一補充不額外增加目標，但任何一天實際完成都計入。

同群組不同器材共用 group.id；下拉與划船不同群組。先排除已達本週目標及當天鎖定的群組，再用原定當日群組、近兩個日曆日部位重疊排序。部位重疊降低優先，不是禁止訓練，也不是科學測量的恢復判斷。提示有重疊時請依自身狀態決定是否採用。

每天最多三項，不為追補而增加動作；目標全部完成時不強制新增推薦。未來日期的建議只根據目前完成紀錄，沒有假設尚未發生的訓練會完成；同一群組可能出現在多個未來日的候選推薦，當實際完成後再更新。推薦不是自動套用，原定課表與你已選的項目不會背景更動。

## 保存

localStorage 保存今天及前 13 天，共 14 個台灣日期；開啟頁面時清理過期紀錄。每日只清除過往的「目前進行」狀態，不清除完成紀錄；每週一重新計算本週完成量。不上傳資料、不需登入、不跨裝置同步。

舊版只存星期，無法可靠判斷实际訓練日期，因此不自動轉成歷史紀錄。本版首次開啟從空白紀錄開始；舊資料不會被冒認為今天完成。

## 編輯課表

唯一課表檔為 workout-plan.js。修改 days 中的 title、groups、options、reps 即可。每份課表三個群組，每群至少一個器材。group.id 是穩定訓練群組代碼，同目的在不同天出現時使用相同 id；同 id 的內容保持一致。muscles 是重疊排序用的部位標籤，例如胸推同時使用 chest 與 shoulders。動作 id 保持穩定。個別 option.reps 可覆蓋群組組次。

歷史紀錄保存當時的群組名稱、動作名稱和部位，不因改課表改寫；今天被移除的群組或器材會從當日安排移除。原始 86 項動作及舊課表背景保留在 workout_plan.md，以本 README 和目前 JS 資料為準。
