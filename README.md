# 今日訓練

純靜態手機版健身課表，可直接使用 GitHub Pages，無編譯步驟。

## 上線

將 index.html、workout-plan.js、.nojekyll 放在同一個 repository 根目錄。GitHub repository 的 Settings → Pages 選擇 main 分支、根目錄發布。README.md 與 workout_plan.md 可一起上傳供參考。請上傳解壓後的檔案，不是 ZIP 本身。

## 只改一份課表檔案

**只需編輯 `workout-plan.js`，不需要修改 index.html。**

- `revision`：課表版本。每次修改後加 1，讓舊進度重設，避免對到不同動作。
- `walking`：訓練後快走提醒文字。
- `days`：0 週日、1 週一、2 週二、3 週三、4 週四、5 週五、6 週六。
- 每天的 `title`：當天訓練部位。
- `groups`：三個動作群組，依順序是第 1、2、3 項；休息日使用空陣列 `[]`。
- 群組 `title`：如「固定式下拉」。
- 群組 `reps`：如「4 組 × 8–12 下」。
- `options`：此群組可選的動作，第一個是預設選擇。
- 動作 `id`：穩定的數字編號，同一群組內不能重複。
- 動作 `cn`、`en`：中文、英文名稱。
- 動作可另加 `reps` 覆蓋群組組次，用於秒數或單側訓練。

例如替換某個可選動作：

```js
{
  "id": 80,
  "en": "Seated Leg Curl (Machine)",
  "cn": "坐姿腿彎舉"
}
```

請保留引號、逗號、括號，每個重訓日保留三個群組，每群至少一個選項。修改完成後儲存、提交 GitHub，等待 Pages 更新並重新整理。若手機仍顯示舊內容，強制重新整理。Markdown 是原始規劃參考，不是網頁資料來源。

## 週一

預設羽球，可切換「補充重訓」：下拉、腿彎舉、肩推。三項自由排序。切換回羽球不會清掉週一的重訓進度，同一個月再切回重訓可繼續。

## 保存規則

同一瀏覽器保存當月各星期的器材選擇、目前項目與完成狀態。每月 1 日 00:00（台灣時間）全部重設，週一模式也回到羽球；沒有歷史紀錄與跨裝置同步。完成項目若要換器材，先取消完成。課表更新 revision 後也會重設舊進度。

## 驗證範圍

JavaScript 邏輯已檢查週一模式、進度保存、週別隔離、同月跨日保留、跨月與課表版本重設。環境無可用瀏覽器，尚未完成真實瀏覽器的視覺及觸控驗證。

同月每週共用各星期的一份進度，不是每日歷史紀錄；下週同一天會保留上週勾選，可手動取消完成重新使用。關閉網頁時不執行背景工作，下次開啟會檢查月份並清除過期進度。升級沿用同月的舊版進度。
