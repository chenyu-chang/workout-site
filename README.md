# 本週訓練清單 v9

只做三件事：選器材、勾選完成、查看紀錄。

- 12 個訓練群組，每週每群組完成一次。不限日期與順序。
- 選擇實際器材，完成全部正式組後勾選，記錄台灣時間的實際日期。
- 可取消完成；不記重量、次數或逐組進度。
- 同週跨天保留完成狀態。每週一開始新清單，最近 14 天紀錄仍可查看、取消。
- 右上角按鈕刷新網頁；紀錄只在同一瀏覽器，不跨裝置同步。
- 相容 v8 有日期的完成紀錄；同一群組本週做多次，清單仍只計一項。在清單取消完成會撤回該群組本週全部完成；歷史紀錄區可單筆撤回。
